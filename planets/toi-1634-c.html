TOI-1634 c

TOI-1634 c is a frozen water-rich world orbiting a red dwarf star 115 ly away. Its star system has 2 stars. A year there lasts 103 days. It was found using the radial velocity method: it makes its star wobble. Planets this size may be wrapped in thick gas; the game imagines it as a solid or water world you can walk on. Note: its size is unknown, so the game assumes one, its temperature is unknown, so the game assumes one.
