GJ 667 C c

GJ 667 C c is a temperate water-rich world orbiting a red dwarf star 23.6 ly away. Its star system has 3 stars. A year there lasts 28.1 days. It was found using the radial velocity method: it makes its star wobble. Its temperature could allow liquid water, which makes it a habitable-zone candidate, not a confirmed habitable world. Planets this size may be wrapped in thick gas; the game imagines it as a solid or water world you can walk on. Note: its size is estimated from its mass, only a minimum mass is known, its temperature is unknown, so the game assumes one. It sits where a planet could be warm enough for liquid water, in the so-called habitable zone.
